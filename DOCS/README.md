# Documentation Index

`MVP_MASTER_SPEC.md` is the current canonical English project specification.

Active project documentation should be written in English. German may be used in user-facing product text, demo content, and historical notes.

The older `MVP_*.md` files are retained as historical concept notes. They contain useful context, but they are not fully consistent with each other. If an older file contradicts `MVP_MASTER_SPEC.md`, use the master specification as the source of truth.

Recommended reading order:

1. `MVP_OVERVIEW.md` for a non-technical project overview
2. `MVP_MASTER_SPEC.md` for the canonical English project specification
3. `IMPLEMENTATION_ROADMAP.md` for the practical development phase plan
4. `CODING_STANDARDS.md` for code quality, naming, and architecture rules
5. Older `MVP_*.md` files only when historical context is needed
